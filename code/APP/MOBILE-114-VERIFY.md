# 114 安卓修复验收

版本号 114。需要重新云打包并安装；资源编译和 Kotlin 类型检查不等于完整 APK 或真机验收。

## 本次变化
- 注册/修改密码固定底部操作改用独立 View + Text 的 LoginButton，保持 48px 高度和加载反馈。
- 事件详情停止按钮改为 40px 高度容器，文字独立居中，避免 Android Text 内边距裁切。
- 安卓 SSE 通过原生 HTTP 输入流逐段读取 UTF-8 数据。观察超时覆盖服务端 25 秒窗口；切后台主动关闭观察，不取消已提交任务。
- 思考实时增量展示；正文仍以服务端成功结果为准，成功后分批呈现文字。没有把尚未执行完成的模型草稿当作成功结果，也没有修改服务端。
- 安卓本机闹铃接入 AlarmManager，使用任务的明确未来时间，设置后显示北京时间。支持取消、事件时间变更后重新同步、账号隔离和重启后恢复未来闹铃。
- 首次设置需允许通知与“闹钟和提醒”权限。授权页返回后再次开启。响铃使用系统闹钟音量，通知栏可停止，最长一分钟；不强行打开锁屏全屏页面。

## 真机检查
1. 登录页打开注册，长表单滚到底部及键盘展开/收起后，注册按钮完整且可点击；缺少姓名时显示校验错误。
2. 登录后打开自己发起的活动事件：停止按钮文字居中，点击取消确认框不得停止事件。
3. 发送一条测试消息，展开思考，观察增量；成功后正文逐步出现。生成中切后台再回来，不能重复创建事件或卡在忙碌状态。
4. 给自己接收的事件设定两分钟后的任务时间，开启闹铃。无权限时有明确引导；授权后重新开启，应显示具体响铃时间。
5. 回到手机桌面等待：到点有响铃和通知，点“停止响铃”立即结束；再测取消后不响、更改事件时间后按新时间响。
6. 切换账号或退出登录后，旧账号的闹铃不得响起。系统闹钟音量需非零；省电或厂商限制仍应在该机型实测。

当前已连接的手机仍为 113 版，尚未安装 114；以上新功能尚不能视为新版真机验收通过。
