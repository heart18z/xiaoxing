# 113 版移动端回归

安装新包前确认 manifest.json 的 versionCode 为 113。资源编译和本地 Kotlin 类型检查不等于云打包及真机验收。

## 真机必测

1. 安卓：在事件列表、事件详情、聊天历史、好友列表、设置及抽屉内上下拖动；确认能到达首尾，头部与底栏保持正常。
2. 安卓：空聊天输入框应紧凑，多行输入自然增高；拼音选词时等待后台刷新，未确认的拼音不能被覆盖。
3. 安卓：点击麦克风，确认录音状态；说一句话后确认，应转成草稿而不自动发送；取消不提交录音。录音占用或启动失败应给出提示。
4. iOS：点击登录后立即出现“正在登录…”与转圈，计算期间动画继续；重复点击不重复请求，失败后可重试。
5. 两端：关联事件最多三行，超出显示省略号；“查看全部”“退出登录”字重增加；思考栏分隔线两侧留白缩小。
6. 安卓：登录并开启通知，确认通知栏显示“AI小醒正在后台接收提醒”；返回桌面保留应用运行，等待另一台设备产生新提醒，约 15 秒检查周期后应出现事件通知；点击通知进入对应事件。
7. 安卓：同一提醒不重复弹出；退出登录停止后台接收并清除通知；切换账号不显示旧账号的新提醒。

## 后台接收范围

本版使用原生前台服务检查新事件，并显示常驻接收通知。未接入 UniPush 或厂商离线推送，不覆盖用户结束进程/划掉任务后的离线接收。网络、系统省电策略和服务运行时限仍可能导致延迟或停止。登录失效时提示打开应用重新登录。首次检查只建立历史基线，不批量弹出旧消息。
