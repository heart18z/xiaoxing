# AI小醒 1.0.137 更新说明

## 功能变化

1. 界面语言默认跟随系统，仍可手动选择中文或英文；补齐手机通知设置的英文文案。返回应用时重新检查系统语言，并同步有效语言到服务端，历史消息保留原文。
2. 输入区图片使用可换行缩略图，不显示文件名，提供加载指示和删除入口；发送后的图片以紧凑网格展示，点击可查看原图。上传过程中删除的图片不会因请求完成重新出现。
3. 本机闹钟仅在设备支持、事件属于本人且存在有效未来时间时显示。明确要求设置闹钟的候选事件自动勾选；AI可根据事件性质建议提前量，明确指定响铃时间则保留该时间。事件时间与闹钟时间分别保存，不使用下一次AI评估时间代替闹钟时间。已有闹钟保留取消入口。
4. 新增阿里云 Fun-ASR Flash 语音协议适配，兼容原语音渠道。使用上传音频的真实格式，以内联音频JSON调用完整服务地址；当前交互等待完整转写结果，未使用SSE逐字展示。

## 发布与使用

- 客户端版本为 1.0.137（137），需要在 HBuilderX 重新编译、签名和安装；后端更新不会自动替换已安装客户端。
- 后端发布标记：`mobile137-20261015`；健康检查已通过。
- 新语音渠道为试用渠道，不修改现有默认渠道。在设置的语音识别模型中选择“Fun-ASR Flash（试用）”并保存后试用。
- API Key仅通过隐藏输入传入安装脚本，加密保存于服务端，不写入源码或文档。

## 验证记录

- APP 自动化测试 89 项通过，最终针对性回归 27 项通过。
- 后端语言、闹钟和语音协议回归 24 项通过；既有账号访问回归通过。
- Android 资源构建和生成的 Kotlin 编译通过；iOS 资源构建与生成桥接检查通过。这不代表已完成签名安装或真机验收。
- H5 页面检查覆盖六张图片、窄屏、上传中删除、发送图片网格、英文通知设置和跟随系统选项。
- 五秒合成音频调用新渠道得到正确转写：WAV约6.51秒、MP3约5.27秒。此为单次链路验证，不构成比原渠道更快的结论，因此保留原默认渠道。

## 发布脚本说明

`scripts/run-mobile137-release.py` 是远程运维辅助脚本，不是APP运行依赖。其参数分别为：

- `prepare`：上传补丁并构建后端镜像。
- `cutover`：切换后端并等待健康检查。
- `rollback`：恢复发布前后端。
- `channel`：仅新增试用语音渠道，已有同名模型时拒绝覆盖。
- `status`：读取容器健康状态与镜像版本。

SSH密码和语音密钥均在连接前通过隐藏输入读取，连接启用保活；渠道安装命令限制90秒。数据库字符串显式使用兼容排序规则，避免服务器默认排序规则差异导致配置失败。

参考：[uni-app x 国际化](https://doc.dcloud.net.cn/uni-app-x/i18n.html)、[阿里云录音文件识别说明](https://help.aliyun.com/en/model-studio/non-realtime-speech-recognition-user-guide)。
