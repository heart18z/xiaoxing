# 个人事件报告与周报

APP 实现在 `code/APP`；管理页面为 `code/front/src/views/smartReminder/reports.vue`，未扩展已停用的 front 手机页面。

- 用户问询：AI 识别 `generate_report`，服务端读取本人有权访问的事件，返回 Markdown 和 `REPORT_LINK`。查看、PDF、Word 均指向同一份不可变报告。
- 自动发送：`WEEKLY_REPORT` 消息，包含摘要、统计和报告编号；APP 以三页底部弹层显示明细。旧 APP 仍可显示消息正文摘要。
- 周报头图按原始比例显示；概览使用可选择的原生文字呈现 Markdown 加粗与列表，旧纯文字快照仍可查看。进展点击展开建议，下周建议按分类展示并对同类事件编号去重计数；“统计口径”入口保留快照说明。
- 默认每周一 09:00（北京时间）汇总上一个完整自然周。后台可调整星期、小时、全局开关和个人开关，也可指定用户和日期生成、预览、手动发送。
- `ReportSchema` 启动时增量建表并添加“事件周报”管理菜单；后台接口要求管理员，APP 下载和详情要求登录用户拥有该报告。
- 接收人只纳入自己分支的任务、事实和进展；发起人可汇总自己发起事件的各分支。自发自收按事件去重。
- 统计包含期间创建或仍在跟进的事件，状态为生成时快照；期间进展单独读取时间轴。有明确完成依据的结束事项才计为完成，取消与其他停止另计。模型不能修改统计或创建、更新事件。
- 生成请求有幂等键、租约和重试退避。自动生成每轮最多 10 人、每份最多尝试 5 次；无事件不自动推送。发送采用事务及唯一投递键，记录操作人和发送时间。全局/个人关闭不影响明确的管理员手动发送。
- PDF 内嵌 Noto Sans SC（OFL 授权文件随字体提交），Word/PDF 使用保存的 Markdown 快照，不会随事件后续变化而改变。

验证：`scripts/WeeklyReportRegression.java` 在隔离 H2 中验证范围、隐私、统计、幂等发送、定时与个人开关、问询无写事件副作用和导出；APP 单测验证问询链接保留、周报在思考期间延后展示。浏览器截图来自 APP 源码编译的 H5，使用虚构数据；安卓 Kotlin 编译及 iOS 资源编译不替代真机手势、推送和文件打开验证。
