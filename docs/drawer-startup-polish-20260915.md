# 侧栏与启动加载优化（2026-09-15）

## 侧栏

- 按参考图增加日期范围、还原、全部 / 我发起的 / 我收到的，以及彩色状态标签。
- 默认全部归属、日期不限；还原清空日期并恢复全部归属。日期区间两端包含，使用北京时间，按卡片实际显示日期筛选；未定时间的卡片在选择日期后不展示。
- 日期筛选先作用于每个接收人分支，再按事件合并，避免把区间外的分支错误合并进来。
- “全部”并行读取已有 sent / received 授权接口，保留来源用于详情跳转，不新增后端权限或接口。
- 四组名称及颜色贴近参考图。内容区独立滚动，头部筛选与底部说明保持可见。
- 仍沿用已有分组语义：待提醒以计划评估时间为依据，不保证必然发送通知；已提醒必须有实际 REMINDER_SENT 记录。不虚构数据库不存在的软删除标识。

## 启动

- 原生入口和 /app 网页入口在业务脚本执行前显示独立、内联关键样式的启动封面，管理端保留原来的启动画面。
- 初始路由与懒加载页面渲染后淡出封面；不引入人为等待。
- 15 秒仍未完成显示“加载较慢”，支持重试。模块加载失败显示友好错误，不暴露原始异常。
- 原生样式在主应用挂载前载入。原生集成初始化失败不会再清空已经渲染的页面。
- 重试会重新加载页面，不修改账号数据或重发业务消息。
