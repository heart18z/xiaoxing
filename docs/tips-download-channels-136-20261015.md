# 1.0.136：浅色顶部提示与下载渠道开关

## APP 提示

顶部提示改为浅蓝白渐变圆角浮层、蓝色柔和阴影、深色文字，参照用户提供的设计。成功使用绿色圆形勾选，普通提示使用蓝色图标，错误使用柔和粉色图标；图标外侧保留浅色光圈。增加右侧关闭按钮，保留 240ms 滑入/缩放/淡出和自动消失，兼容长文本与安全区。

原生版本为 `1.0.136 / 136`，需重新通过 HBuilderX 打包安装。服务器更新不会直接改变已安装 APP 的提示样式。

## 下载渠道

APP 版本管理的“统一下载页”中统一展示 Android、iOS、鸿蒙三个渠道开关。Android/iOS 复用现有配置，鸿蒙新增总开关；关闭后下载页入口仍显示，但置灰且不能通过鼠标或键盘触发，也不弹出适配中提示。

鸿蒙总开关停用 APK 和原生商店两个入口，不清空其原有选项与链接。各子入口关闭时同样禁用。公开 APK 接口仅在 Android 开启或“鸿蒙总开关 + APK 兼容版”同时开启时开放。页面获取配置期间及网络失败时禁用入口，重试成功后恢复对应状态。

`blade_app_download_page` 幂等增加 `harmony_enabled` 字段，默认 1，兼容之前一直显示的鸿蒙入口；已有开关及链接不改变。旧后台页面保存时若未携带新字段，会保留当前鸿蒙总开关状态，不会意外重新开启。
