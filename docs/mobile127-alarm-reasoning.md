# APP 127：响铃控制与切页后思考闪烁

版本：`1.0.127` / `versionCode 127`。包含 APP 126 的安卓安装更新修复。

## Android 响铃入口

- 原生服务记录当前响铃事件，提供账号隔离的查询、打开、停止操作。
- App 前台响铃时主动显示原生闹铃页；各主页面另有“正在响铃”横条和“停止响铃”按钮，返回 App 时也会刷新状态。
- 通知注明“正在响铃”，保留打开闹铃页与直接停止操作。停止按钮有明确反馈。
- Android 14 及以上未允许全屏提醒时，事件详情提供系统权限入口。后台或锁屏能否自动展示全屏仍由系统权限和厂商策略决定；App 内停止入口不依赖这项权限。
- 保留原有 60 秒自动结束行为，不改动业务事件或提醒时间。

## iOS 切页后思考内容闪烁

- 菜单切换只暂停页面动画和显示计时器，不中断正在进行的流式请求；整个 App 进入后台时仍按原有逻辑暂停连接。
- 返回聊天直接展示已收到的思考内容，不从空文本重放，也不重新播放展开高度动画。
- 同一任务的累计进度不再被较短或空的旧快照覆盖；新任务仍重置内容，最终结果仍按服务器结果处理。
- 思考区使用消息独立的滚动元素，节流跟随滚动，取消每段文字清空滚动锚点；固定高度区域的文字增长不再重复触发外层滚动。

## 验证

- Node 回归测试：73/73 通过，含持续接收、隐藏后返回、旧快照回退与 Unicode 片段场景。
- Vue/UTS、JSON、路由检查通过：27 个组件/页面、34 个 UTS 模块。
- HBuilderX 5.24 Android 和 iOS 资源构建通过。
- 全部 Android 生成页面、共享 Kotlin 与原生 Android 实现编译通过。
- iOS 生成桥接检查通过：流式回调保持存活，普通调用为一次性回调。

资源构建和 Kotlin 检查不等同于签名 APK/IPA 云打包，也不等同于 iPhone 真机验证。安装新版本后需复核 iOS 流式输出时连续切换菜单，以及 Android 前台、后台、锁屏三种状态下的响铃和停止操作。
