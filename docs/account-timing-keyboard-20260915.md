# 注册联系方式、事件时间展示与键盘跟随

本轮为本地修改与隔离测试，未部署、未提交/推送 Git、未执行线上 SQL。

## 注册

- 账号占位文字改为“账号”；默认密码改为 admin@123，仍可手动修改、显示/隐藏。
- 手机号和邮箱至少填写一项；两项均填时两项都校验。账号继续保持4–32位校验。
- Bean Validation 和注册服务都拒绝没有任何联系方式的请求。
- 后端对现有手机号、邮箱查重；注册邮箱统一 trim + lowercase。
- 新增 sql/app-contact-unique.sql：按 tenant_id 分别约束非删除用户的非空手机号、邮箱。包括普通用户、管理员和禁用账号；空联系方式不互相冲突，历史无联系方式用户无需补填。
- 索引中的生成列对手机号 trim，对邮箱 trim + lowercase；注册、编辑资料、管理员操作和并发请求均由数据库最终仲裁，不只依赖“先查再插入”。
- 重复数据不自动清理。先执行脚本里的两条只读查重语句，人工确认历史冲突后，再安装唯一索引。新后端在索引缺失时拒绝注册，不降低唯一性要求。
- 编辑资料发生联系方式重复时返回友好错误；保留原有历史账号可清空可选联系方式的兼容行为。不能借此设置重复联系方式。

## 时间展示

原因：发起人原先读主事件时间；接收人读独立分支时间，部分接收人改期不会覆盖主事件。因此可能出现概要/分支为13点，发起人事件时间仍为15点。

- EventTiming 为只读展示投影，优先采用 ACTIVE 分支；没有 ACTIVE 分支时展示历史分支。
- 各有效分支时间一致：发起人展示共同时间；不一致：显示“按接收人分别设置”，并在各接收人卡片显示实际时间。
- 空时间和已停止分支不会错误覆盖当前有效分支的安排。
- 发起人列表、详情与接收人列表、详情统一采用对应分支时间。
- 未修改数据库主事件/分支时间，不把单人改期广播给其他人，不改变 AI 评估和闹铃的业务权限。

## 键盘

- 在 keyboardWillShow/Hide 修改布局前通知聊天页。
- 输入框聚焦、键盘布局变化时，处于最新消息跟随状态的列表在动画过程中跟随底部。
- 同时观察输入区与消息区尺寸，避免仅缩小可视区域却留在旧滚动位置。
- 触摸/滚轮翻阅历史可中止动画跟随；离开页面清理动画与监听。键盘收起不强行打断历史阅读。

## 验证与上线

- 前端16项单元回归、前端 Native/Production 构建、后端 Maven package。
- AccountRegression：至少一项联系方式、索引缺失阻止注册、手机号重复、邮箱大小写/空格规范化重复、不同账号并发同邮箱只有一个成功、数据库拒绝编辑为已占用联系方式。
- EventTimingRegression 与 EventTimingIntegrationRegression：只读共同/分人时间、发起人和接收人列表/详情一致、历史与隐私回归。
- Playwright CLI + 隔离 API/原生桥模拟：注册错误提示、邮箱单项注册、390/320键盘上顶跟随最新和手动翻历史、分人时间展示。
- 运行时无线上 API/model/真实联系人写入。MySQL 8 迁移脚本尚未在线上执行；H2 测试验证对应生成列/唯一约束语义，不替代实际部署前查重。
- iPhone 真机键盘动画仍需新 TestFlight 包验收；浏览器截图中的键盘区域为空白是模拟键盘高度，不是实际 iOS 键盘。

部署顺序：备份 → 只读检查历史重复 → 确认冲突处理 → 安装联系人唯一索引 → 同步后端和前端 → 新包验收。默认密码为共用初始值，建议用户注册时改成自己的密码。
