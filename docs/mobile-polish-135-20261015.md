# APP 1.0.135：弹窗、反馈与事件切换

本次仅修改 `code/APP` 客户端，版本名称/代码为 `1.0.135 / 135`。拉取代码后需要重新通过 HBuilderX 打包安装，现有安装包不会自动获得这些页面改动。无需部署后端或迁移数据库。

## 改动

- **确认按钮**：取消按钮原本使用通用 `secondary` 类，与全局主题的 38px 高度冲突；主按钮为 48px，所以只调整父容器宽度无法根治。改为组件专属 `login-submit-secondary`，主次按钮统一 48px 高、零外边距/内边距，登录确认与注销确认两侧等宽。
- **提醒抽屉**：同时提高底色、渐变和卡片的不透明度，避免原生背景渐变覆盖底色后仍透出聊天文字。保留气泡、分组颜色、90% 宽度、点击外侧及左滑关闭。
- **好友申请**：行最小高度由 84px 降至 70px，上下内边距由 18px 降至 12px，头像由 44px 调为 40px；保留双向申请状态及接受/拒绝操作。
- **好友备注**：固定弹窗初始高度，内容单独滚动，保存/权限操作固定在底部；关闭输入框自动顶起，改由弹窗按键盘高度调整可用区域并滚动到输入框，避免两套避让同时推动页面。已考虑窗口被系统缩小的情况，避免重复减去键盘高度。关闭和保存时收起键盘。
- **顶部反馈**：深色高对比背景、白色文字、状态色图标与阴影，增加 240ms 上移/缩放/淡入淡出；成功保存使用绿色反馈。仍根据真实设备安全区避开状态栏。
- **事件切换**：进入页面并行请求“我发起的”和“我收到的”，两个列表在原生 swiper 中持续挂载；点击/横滑仅切换缓存和执行 260ms 过渡，不请求、不清空列表、不触发刷新，并保留独立滚动位置。保留手动下拉刷新、状态筛选和原有后台轮询。单组请求失败不清空另一组；离页/换账号后忽略过期响应。
