# 聊天展示优化（2026-09-16）

## 原因

息屏恢复改为持久化后台任务后，前端轮询任务状态；正常的 QUEUED 状态也展示顶部横幅，思考内容随轮询成段更新，正文在最终结果返回后一次性显示。

## 本次修改

- 正常排队、运行状态不再展示顶部排队横幅，仅保留消息气泡内的处理状态。
- 新增只读 `/app/reminder/chat/jobs/watch` SSE 观察接口，实时传递当前任务的思考快照；连接断开不取消任务，不重复提交消息。
- 旧服务器不支持观察接口或观察连接失败时，静默回退到原状态查询；保留息屏恢复、账号隔离和幂等执行。
- 正文在后台事务提交成功后渐进显示，动画最多约 640 ms；减少动态效果设置下立即显示。
- 正文不是模型原始 token 的提前透传。事件操作仍在提交成功后才向用户确认，避免提前显示“已修改”但实际执行失败。
